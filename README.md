# Maaş ve verimlilik raporu

**Gün 4 · C# günlük çalışma**

Çalışma saatlerine göre prim ve toplam maaş hesaplayan C# konsol örneği.

## Çalıştırma

Visual Studio ile kökteki `.slnx` dosyasını açın veya `dotnet build` komutunu çalıştırın. Mevcut projeler .NET Framework 4.8 hedefler; Windows ve ilgili hedefleme paketi gerekir.

## İçerik

- `Program.cs`: örnek uygulama ve ilgili sınıflar.
- `.slnx` / `.csproj`: Visual Studio çözüm ve proje tanımları.

Bu repo, bir aylık öğrenme planının 4. günündeki küçük çalışma örneğidir.
